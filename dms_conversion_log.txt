Method: GetLowStockProductsAsync(int threshold)

Key changes for PostgreSQL:

WITH StockAnalysis AS (

Method: GetLowStockProductsAsync(int threshold)

DMS CONVERSION ATTEMPT:
Not attempted due to consistent DMS metadata model creation failures.
Status: SKIPPED_DUE_TO_PREVIOUS_FAILURES

MANUAL CONVERSION APPLIED:
Key changes for PostgreSQL:
1. AVG/MIN/MAX window functions - fully compatible

WITH StockAnalysis AS (
    SELECT 
        p.*,
        AVG(StockQuantity) OVER() as AvgStock,
        MIN(StockQuantity) OVER() as MinStock,
        MAX(StockQuantity) OVER() as MaxStock
    FROM Products p
)
SELECT 
    sa.*,
    CASE 
        WHEN StockQuantity <= @Threshold THEN 'Critical'
        WHEN StockQuantity <= AvgStock * 0.5 THEN 'Low'

FROM StockAnalysis sa
WHERE StockQuantity <= @Threshold
ORDER BY StockQuantity;
