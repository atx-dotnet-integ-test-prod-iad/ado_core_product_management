## ProductRepository Connection String Usage

### Constructor
```csharp
public ProductRepository(IConfiguration configuration)
{
    _configuration = configuration;
    var environment = _configuration["Environment"];
    var connectionName = environment == "Production" ? "ProdConnection" : "DevConnection";
    _connectionString = _configuration.GetConnectionString(connectionName);
}
```

The constructor correctly:
- Reads the Environment configuration
- Selects appropriate connection string (Dev or Prod)
- Uses GetConnectionString method for retrieval
