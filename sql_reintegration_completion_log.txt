TRANSACTION HANDLING APPROACH
------------------------------
Strategy: Application-Level Transaction Management using NpgsqlTransaction

Methods with Transactions:
1. InsertProductAsync - Multi-step insert with RETURNING, history logging, stats update
2. UpdateProductAsync - Select old values, update, log changes, update stats
3. DeleteProductAsync - Select old values, log deletion, delete, update stats

Transaction Pattern Applied:
```csharp
using var transaction = await connection.BeginTransactionAsync();
try
{
    // Execute multiple SQL commands within transaction
    // Each command receives the transaction object
    await transaction.CommitAsync();
}
catch
{
    await transaction.RollbackAsync();
    throw;
}
```

This approach replaces SQL Server's "BEGIN TRANSACTION" / "COMMIT" syntax which PostgreSQL
does not support in the same way when executed as ad-hoc SQL statements.
