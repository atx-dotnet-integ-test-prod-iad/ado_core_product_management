## Manual Interventions
All 7 SQL statements required manual conversion due to DMS tool failure. Conversion method: DMS_FAILURE_MANUAL_CONVERSION_WITH_LOWERCASE_SCHEMA.

Key manual conversion decisions:
1. **SCOPE_IDENTITY() replacement**: Used `lastval()` function which returns the last value generated by a sequence in the current session
2. **DECLARE @var removal**: Replaced SQL Server variable declarations with PostgreSQL subqueries for transactional statements
3. **Transaction syntax**: Changed `BEGIN TRANSACTION` to `BEGIN` for PostgreSQL compatibility
4. **Schema object names**: All converted to lowercase per PostgreSQL conventions
5. **Integer division**: Added explicit `CAST(... AS DECIMAL)` in GetLowStockProducts to prevent integer division truncation
6. **MapProductFromReader**: Updated column name references to lowercase to match PostgreSQL query output
