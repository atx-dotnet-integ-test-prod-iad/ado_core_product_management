   - PostgreSQL: Same support, but moved to application level for clarity

   - SQL Server: DECLARE @var within SQL batches
   - PostgreSQL: Requires DO blocks or application variables
   - Impact: Used C# variables for clarity (completed)

- Npgsql ADO.NET provider supports @param syntax
- No parameter syntax changes required in SQL or C# code

Performance Considerations:
- Window functions: Same performance characteristics
- CTEs: PostgreSQL may optimize differently (monitor in testing)
