NPGSQL COMPATIBILITY
--------------------
Npgsql 8.0.5 provides:
- Full ADO.NET API compatibility (DbConnection, DbCommand, DbDataReader, etc.)
- Support for PostgreSQL-specific features
- Parameter binding with @parameter syntax (compatible with existing code)
- Async/await support for all database operations
- Transaction management (BeginTransaction, Commit, Rollback)
- Connection pooling
- PostgreSQL data type mapping
- RETURNING clause support
- Window functions and CTEs (used extensively in this application)
